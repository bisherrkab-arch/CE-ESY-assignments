# Assignment 1: Circular Buffer (CE-ESY)

## عن المشروع
هاد المشروع هو تنفيذ بسيط لمفهوم المخزن الدائري (Circular Buffer) باستخدام لغة C. الهدف منه هو إدارة الذاكرة بشكل ذكي بحيث لما نوصل لآخر المصفوفة نرجع للبداية بشكل تلقائي، وهاد الشي بيساعد بتوفير المساحة في الأنظمة المضمنة.

## كيف بيشتغل الكود؟
 استخدمت `struct` بيحتوي على:
- مصفوفة (Array) لتخزين الحروف.
- مؤشرين واحد للقراءة (head) وواحد للكتابة (tail).
- عداد (count) عشان نراقب كم عنصر صار بالمخزن بكل لحظة.

### الدوال الأساسية اللي كتبتها:
- **setupBuffer**: بتجهز المخزن وبتصفر كل المؤشرات بالبداية.
- **pushData**: بتضيف الحروف للمخزن، وإذا امتلأ بتطبع رسالة (Buffer Overflow).
- **popData**: بتسحب الحروف من المخزن، وإذا كان فاضي بتطبع (Buffer Underflow).

## تجربة البرنامج والاختبار
 جربت البرنامج بحالتين:
1. **الحالة الأولى (حجم كافٍ):** لما كان حجم المخزن أكبر من الاسم، الكود خزن الاسم واللاحقة "-CE-ESY" وطبعهم بشكل كامل وصحيح.
2. **الحالة الثانية (حجم صغير):** لما صغرت حجم المخزن (MAX_SIZE) وجربت أدخل اسم طويل، الكود طبع رسائل تنبيه إنو المخزن ممتلئ (Overflow) وما سمح بتجاوز سعة الذاكرة، وهاد الشي بيثبت إنو منطق الحماية شغال صح.

## ملاحظة أخيرة
بعد القراءة، الكود بيتحقق إنو المخزن صار فاضي تماماً (count = 0) لضمان إنو كل البيانات تمت معالجتها بشكل سليم.
